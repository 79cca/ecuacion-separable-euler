# Ecuación diferencial separable y método de Euler

## Problema

Resolver la ecuación diferencial separable:

**dy/dt = -2y**, con **y(0) = 1**.

Se compara la solución exacta con el método de Euler en el intervalo **t ∈ [0,1]**, usando **h = 0.2**.

## Solución analítica

Partimos de:

dy/dt = -2y

Separamos variables:

(1/y) dy = -2 dt

Integramos:

ln|y| = -2t + C

Despejamos:

y = C e^(-2t)

Usando y(0) = 1 obtenemos C = 1.

Por tanto, la solución exacta es:

**y(t) = e^(-2t)**

## Método de Euler

La fórmula es:

**y_(n+1) = y_n + h f(t_n, y_n)**

Como f(t,y) = -2y:

**y_(n+1) = y_n - 2h y_n**

El programa usa h = 0.2 desde t = 0 hasta t = 1 y compara la aproximación de Euler con la solución exacta.

Comparar una solución analítica exacta con una aproximación numérica obtenida mediante el método de Euler.
